# Estimation Agent: Request and Review Guide

This learning project explores how GitHub can organize documentation for an estimation agent. It uses a fictional example and contains no proprietary project information.

## Purpose

An estimation agent needs clearly defined inputs, understandable outputs, and a process for reviewing uncertain results.

## Example Request

Estimate the effort required to add a reporting feature to a fictional application.

Required information:
- Description of the requested feature
- Scope and exclusions
- Available requirements
- Dependencies
- Assumptions and constraints

## Expected Response

An estimate should explain:
- Proposed tasks
- Estimated effort range
- Assumptions behind the estimate
- Missing information
- Risks that could change the estimate

## Human Review

A reviewer should check that the estimate covers the requested scope, identifies uncertainty, and explains its reasoning before it is used for planning.

## Learning Objectives

Use GitHub to track documentation changes, propose improvements through branches and pull requests, and record future work with issues.
